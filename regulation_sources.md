# Regulation sources used for SUPPLYMATE

The regulation selector uses these labels and official source links:

| Level | Regulation | Official source | Notes |
|---|---|---|---|
| Diploma | SBTET C-24 | https://www.sbtet.telangana.gov.in/index.html#!/index/ViewSyllabus | Official State Board of Technical Education and Training Telangana syllabus portal; the uploaded brief identifies C-24 as the Diploma scheme. |
| B.Tech | JNTUH R25 | https://jntuh.ac.in/syllabus | Official JNTUH syllabus page listing current R25 B.Tech syllabus materials. |
| B.Tech | JNTUH R25 CSE reference | https://jntuh.ac.in/uploads/bulletins/R25B.Tech.CSEIIIYearSyllabus.pdf | Official R25 CSE course structure and syllabus PDF; extraction states applicable from AY 2025-2026 and includes semester course structures. |
| Intermediate | TS Intermediate adaptable | No single official regulation URL selected | Kept adaptable because the uploaded brief states Intermediate subjects depend on the relevant Telangana Board stream and year. |

Implementation note: exact subject names can vary by college, board, branch, and regulation year, so SUPPLYMATE presents these as selectable frameworks and keeps an adaptable option where appropriate.
